## About

M.I.V.E is a personal AI assistant inspired by J.A.R.V.I.S

The project M.I.V.E is focused on:
- voice assistance
- study productivity
- automation
- artificial intelligence
- personal workflow optimization

The assistant will be developed using java and Intellij IDEA.

---

## Main Goals

- Help with studies
- Automate tasks
- Open applications using voice commands
- Integrate AI models
- Create a personal productivity assistant
